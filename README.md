# Мафия — приложение-ведущий для Android

Один телефон на весь стол: раздаёт роли, помнит кто есть кто, ведёт ночь и день по
сценарию, считает итог ночи, держит таймеры речей и фолы и сам подкладывает музыку под фазу.

Офлайн, без аккаунтов, без единого runtime-разрешения. Release APK — **~2 МБ**.

## Как идёт партия

1. **Настройка.** Ведущий задаёт число игроков (4–20) кнопками «+ / −». Чёрных приложение
   считает само (≈ треть стола), но их число тоже правится вручную теми же «+ / −» — так партия
   делается сложнее или проще, а подпись сверху говорит, насколько городу тяжело. Переключателями
   включаются **дон / комиссар / врач / бабочка / маньяк** и режим **«первая ночь — в воздух»**.
   Если ролей больше, чем людей, партия не стартует. Здесь же — хронометраж речей.
2. **Раздача.** Телефон идёт по кругу: «Передай телефон игроку N» → игрок **держит палец** на
   карточке и видит свою роль с портретом, отпустил — роль скрыта. Роли записываются в партию.
3. **Знакомство (ночь).** Фракции открывают глаза по очереди отдельными шагами, экран показывает
   ведущему поимённо, кто сейчас должен открыть глаза, — сверка, что никто не перепутал.
4. **Первое знакомство (день).** Круг представлений, каждому по 30 с. Таймер: **старт / пауза /
   сброс**, сигнал по нулю.
5. **Первая ночь.** Если состав перекошен в пользу чёрных, приложение предлагает вариант
   **«мафия стреляет в воздух»** — первая ночь без жертвы, чтобы усилить красных.
6. **Ночь.** Порядок: **бабочка → мафия → дон → врач → комиссар → маньяк**. На каждом шаге сразу
   открыт список живых, ведущий отмечает выбор роли. На шаге комиссара рядом с каждым игроком
   видна его **принадлежность** (красный/чёрный) — ведущий отвечает мгновенно; на шаге дона
   помечен комиссар.
7. **Утро.** Приложение считает ночь: бабочка гасит действие своей цели, врач спасает,
   выстрелы мафии и маньяка применяются независимо. Экран показывает погибших с ролями.
8. **День.** Круг речей по минуте; во время речи говорящий может **выставить** кого-то на
   голосование. Тут же — **фолы**: 1 — предупреждение, 2 — пропуск ближайшей речи (одноразово),
   3 — игрок выбывает. Кнопки «+ фол» и «− снять фол» есть на каждом круге речей, включая
   знакомство, а список фолов стола висит прямо на экране.
9. **Голосование** по выставленным, ничья решается ведущим. Дальше снова ночь — пока не
   победят город, мафия или маньяк.

В любой момент у ведущего под рукой **шпаргалка** (кто есть кто), **журнал партии** и кнопка
«домой» — вернуться к настройкам, если партия началась случайно или стол передумал.

## Музыка

Три фоновых трека (ночь / день / голосование) и сигналы (гонг, утро, выстрел, конец времени)
**синтезированы кодом** — `tools/gen_music.py` (numpy + ffmpeg → ogg, всё вместе ~0.8 МБ),
поэтому ни лицензий, ни веса. Портреты ролей нарисованы `tools/gen_art.py` (Pillow → webp).

Свои треки подключаются на любую фазу через системный выбор файлов (кнопка-ползунки вверху
справа) — без разрешений на хранилище, выбор запоминается между запусками. Мини-плеер внизу
экрана: вкл/выкл, пауза, следующий, громкость.

## Сборка

```bash
./gradlew assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk (~2 МБ)
./gradlew testDebugUnitTest # логика ведущего: 18 тестов
```

Требуется JDK 17 и Android SDK 35. Перегенерация ассетов (нужны только при правке):

```bash
python tools/gen_music.py   # res/raw/*.ogg
python tools/gen_art.py     # res/drawable-nodpi/role_*.webp
```

## Устройство кода

| Файл | Что внутри |
| --- | --- |
| `model/Roles.kt` | роли, фракции, расчёт состава, предложение «выстрел в воздух» |
| `model/Game.kt` | состояние партии, шаги ночи и знакомства, очередь речей |
| `model/GameViewModel.kt` | переходы фаз, разрешение ночи, фолы, голосование, победа |
| `audio/Music.kt` | MediaPlayer, встроенные и свои треки, сигналы |
| `ui/*.kt` | экраны Compose: настройка, раздача, знакомство, речь, ночь, утро, голосование, финал |
| `app/src/test/…/GameLogicTest.kt` | 18 тестов правил (ночь, фолы, победы) |

Спецификация проекта живёт в spec-MCP меша: `spec.mafia` (там же список граблей).
